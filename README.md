# 桌面宠物

Windows 上的 PySide6 桌面宠物，支持 Q 版少女、小幽灵、白色小人、蓝色团子及自定义图片/GIF。可摸头、拖拽、抛掷、聊天，也能坐在窗口上。

## 启动

```powershell
python -m pip install -r requirements.txt
python main.py
```

双击宠物打开聊天，右键或托盘图标打开菜单，输入框按 Esc 关闭。

聊天支持“跳舞”“过来”“坐下”“下来”“安静”“心情”等本地指令。AI 对话需要在设置中启用并填写接口地址、模型及 API Key 环境变量名称；密钥本身从环境变量读取。

配置与导入的图片保存在 `%APPDATA%\DesktopPet`，项目目录里的模型不计入日常运行内存。

## 流畅度与资源占用

- 设置中的“动画帧率上限”支持 10–60 FPS。默认 30；希望省资源可设为 15–20；走动、拖拽希望更流畅可设为 30–60。
- 待机、睡眠会自动降低帧率。隐藏宠物会暂停动画、GIF 和置顶计时器，并停止主动闲聊；重新显示自动恢复。
- 自定义图片的缩放和描边按图片内容缓存。窗口碰撞区域最多每秒重算 12 次，状态变化时立即刷新。
- AI 会话只保留设置允许的最近若干条消息，避免长时间聊天不断积累历史。

## 可选自动抠图

```powershell
python -m pip install "rembg[cpu]" Pillow
```

需要 `u2net.onnx`，可放在项目的 `models` 目录、`%APPDATA%\DesktopPet\models`，或通过 `U2NET_HOME` 指定模型目录。缺少依赖或模型时直接使用原图。

抠图在后台执行，处理完成后释放模型会话；因此下一次抠图会重新加载模型。处理期间请等当前图片完成后再换图。退出时会隐藏界面并等后台任务结束，避免线程被提前销毁。GIF 保留动画，不执行静态抠图。旧图片保留在 assets 目录，防止取消设置时丢失当前形象。

## 验证

```powershell
python -m unittest discover -s tests -v
python tools/benchmark_runtime.py
```

测试使用 Qt 离屏模式，不打开桌面窗口、不请求外部 AI 服务。覆盖点击与落地状态、跟随方向、隐藏暂停、设置更新、图片缓存、抠图退出和聊天资源清理。

基准测试测量离屏单帧绘制耗时及隐藏后的动画更新次数。高速循环中的碰撞区域更新次数受实际墙钟时间影响，不能直接当作日常运行的频率或整机 CPU 使用率。
