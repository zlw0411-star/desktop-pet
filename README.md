# 桌面宠物

Windows 上的 PySide6 桌面宠物，支持 Q 版少女、小幽灵、白色小人、蓝色团子及自定义图片/GIF。可摸头、拖拽、抛掷、聊天，也能坐在窗口上。

## 启动

```powershell
python -m pip install -r requirements.txt
python main.py
```

双击宠物打开聊天，右键或托盘图标打开菜单，输入框按 Esc 关闭。

设置分为“形象 / 行为 / 聊天”三页。形象页可预览四种内置风格和自定义图片/GIF；预览不会切换当前宠物，只有保存后才会导入并应用图片。聊天页可单独关闭主动搭话，并保留现有 AI 地址、模型、备用模型、密钥环境变量和人设设置。未配置 AI 时，普通聊天会使用本地友好回复。

托盘菜单可随时切换专注模式。该模式会减少走动、停止主动搭话并即时生效；关闭后会重新安排搭话时间，不补发专注期间错过的内容。聊天记录只保留本次运行中的最近 20 轮，可复制或清空；清空也会重置本地 AI 对话历史。回复生成期间可停止，失败后可在原聊天轮次重试。

聊天支持“跳舞”“过来”“坐下”“下来”“安静”“心情”等本地指令。AI 对话需要在设置中启用并填写接口地址、模型及 API Key 环境变量名称；密钥本身从环境变量读取。

配置与导入的图片保存在 `%APPDATA%\DesktopPet`，项目目录里的模型不计入日常运行内存。

## 流畅度与资源占用

- 设置中的“动画帧率上限”支持 10–60 FPS。默认 30；希望省资源可设为 15–20；走动、拖拽希望更流畅可设为 30–60。
- 待机、睡眠会自动降低帧率。隐藏宠物会暂停动画、GIF 和置顶计时器，并暂停主动闲聊；重新显示后重新安排闲聊时间。
- 自定义图片的缩放和描边按图片内容缓存。窗口碰撞区域最多每秒重算 12 次，状态变化时立即刷新。
- AI 会话只保留设置允许的最近若干条消息，避免长时间聊天不断积累历史。

## 可选自动抠图

```powershell
python -m pip install "rembg[cpu]" Pillow
```

需要 `u2net.onnx`，可放在项目的 `models` 目录、`%APPDATA%\DesktopPet\models`，或通过 `U2NET_HOME` 指定模型目录。缺少依赖或模型时直接使用原图。

抠图在后台执行，处理完成后释放模型会话；因此下一次抠图会重新加载模型。处理期间请等当前图片完成后再换图。退出时会隐藏界面并等后台任务结束，避免线程被提前销毁。GIF 保留动画，不执行静态抠图。设置取消时不会导入候选图片，已使用的旧图片会保留在 assets 目录。

## 验证

```powershell
python -m unittest discover -s tests -v
python tools/benchmark_runtime.py
```

最终离屏测试套件包含 76 项，覆盖点击与落地状态、跟随方向、隐藏暂停、设置更新、图片预览和取消、损坏配置恢复、抠图退出及聊天控制器集成；不请求外部 AI 服务，也不写入系统启动项。另以模拟信号验证了成功回复、部分回复超时、重试和清空流程，外部请求数为 0。渲染冒烟检查通过 132 种组合（4 种形象、11 种状态、DPR 1 / 1.5 / 2）。几何场景使用模拟屏幕；本次没有手动验证真实多屏或混合 DPI 桌面，也没有验证真实 AI 服务。

本次基准测试运行 3 次，离屏单帧绘制中位数为：少女 0.917 ms，图片形象 0.337 ms；两种形象隐藏 400 ms 后的动画更新次数均为 0。该数据只描述此离屏场景，不代表整机 CPU 使用率，也未验证真实桌面上的渲染表现。测试没有访问真实 AI 服务。
